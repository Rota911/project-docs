# ls_workgroups

Player-formed temporary groups. In-memory only (`ActiveWorkgroups`, keyed by `groupId`) — nothing persists to DB; all groups clear on resource restart. Membership is tracked on the character via the `workgroup` data field.

## Group payload

```lua
---@class WorkgroupPayload
---@field id string
---@field leader { charId: number, playerSrc: number, name: string }
---@field members { charId: number, playerSrc: number, name: string }[]
---@field limit number
---@field locked boolean
---@field inviting boolean
---@field activity any
```

## Callbacks

Invoke with `LS.Callback:Await(name, false, ...)` from the client.

| Callback | Params | Returns | Description |
|---|---|---|---|
| `Workgroups:Server:Create` | `limit` | `boolean, payload?` | Creates a group led by the caller |
| `Workgroups:Server:Leave` | – | `boolean` | Caller leaves their group |
| `Workgroups:Server:SetLocked` | `state` | `boolean` | Leader sets locked state |
| `Workgroups:Server:ToggleInviting` | – | `boolean` | Leader flips open recruiting |
| `Workgroups:Server:KickMember` | `charId` | `boolean` | Leader kicks a member |
| `Workgroups:Server:TransferLeadership` | `charId` | `boolean` | Leader hands leadership to a member |
| `Workgroups:Server:Disband` | – | `boolean` | Leader disbands the group |
| `Workgroups:Server:SendInvite` | `target` | `boolean` | Leader invites a nearby player (server id) |
| `Workgroups:Server:AcceptInvite` | `groupId` | `boolean` | Caller accepts an invite |
| `Workgroups:Server:DeclineInvite` | – | `boolean` | Caller declines an invite |
| `Workgroups:Server:RequestJoin` | `groupId` | `boolean` | Requests to join an open group (rate-limited) |
| `Workgroups:Server:GetUserPanel` | – | `payload\|nil, isLeader` | Caller's group payload + whether they lead it |

Admin callbacks (used by `/wgadmin`, NOT permission-gated server-side — gating is at the command level). Each returns the **full fresh group list** so the panel re-renders from one response:

| Callback | Params | Returns |
|---|---|---|
| `Workgroups:Server:Admin:GetAll` | – | `payload[]` |
| `Workgroups:Server:Admin:ForceDisband` | `groupId` | `payload[]` |
| `Workgroups:Server:Admin:SetLocked` | `groupId, state` | `payload[]` |
| `Workgroups:Server:Admin:SetInviting` | `groupId, state` | `payload[]` |
| `Workgroups:Server:Admin:SetLimit` | `groupId, limit` | `payload[]` |
| `Workgroups:Server:Admin:KickMember` | `groupId, charId` | `payload[]` |
| `Workgroups:Server:Admin:TransferLeadership` | `groupId, charId` | `payload[]` |
| `Workgroups:Server:Admin:ClearActivity` | `groupId` | `payload[]` |

`Workgroups:Client:JoinRequested` (server → client, callback): asks the leader to approve a join request. Params: `characterName: string`. Returns `boolean`.

```lua
local groups = LS.Callback:Await('Workgroups:Server:Admin:SetLocked', false, groupId, true)
```

## Events

Fired server-side via `TriggerEvent`; other resources can `AddEventHandler` on them.

| Event | Args | Description |
|---|---|---|
| `Workgroups:Server:Created` | `workgroup: Workgroup` | New group created |
| `Workgroups:Server:Removed` | `groupId: string` | Group removed |
| `Workgroups:Server:Disbanded` | `groupId: string` | Group disbanded |
| `Workgroups:Server:MemberAdded` | `groupId, character` | Member added |
| `Workgroups:Server:MemberRemoved` | `groupId, character` | Member removed (`{charId}` only if offline) |
| `Workgroups:Server:LeaderChanged` | `groupId, newLeader` | Leadership transferred |
| `Workgroups:Server:LeaderDisconnected` | `groupId, oldLeaderCharId, newLeaderCharId?, disbanded` | Leader logged out; auto-promotion or disband |
| `Workgroups:Server:SettingsChanged` | `groupId, { locked, inviting }` | Locked/inviting flags changed |
| `Workgroups:Server:ActivityChanged` | `groupId, activity?` | Activity tag changed/cleared |

Client-side pushes (`TriggerClientEvent`):

| Event | Args | Description |
|---|---|---|
| `Workgroups:Client:OpenAdminPanel` | `workgroups: payload[]` | Opens `/wgadmin` panel |
| `Workgroups:Client:UpdateGroup` | `groupData: payload\|nil` | Live push to a member; `nil` closes their panel |
| `Workgroups:Client:ReceiveInvite` | `groupId, leaderName` | Incoming invite |

```lua
AddEventHandler('Workgroups:Server:Disbanded', function(groupId)
    print(('workgroup %s disbanded'):format(groupId))
end)
```

## Disconnect handling

On `Core:Server:CharacterLogout`, membership is cached in `droppedCharacters` for a grace period. If the leader disconnects, leadership auto-transfers to the first member, or the group is destroyed if empty. On `Core:Server:CharacterLoaded` within the grace period, member info refreshes. A 1-minute `LS.Cron` removes characters gone ≥ 5 minutes.

> No `GlobalState`/state-bag contract. Read membership via `LS:GetCharacter(id):GetData('workgroup')`.
