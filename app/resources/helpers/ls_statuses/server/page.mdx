# Server

Decays statuses every minute via `LS.Cron` and persists them on `character:SetData('statuses', ...)`. Labor auto-increases on a separate cron and on character load (offline accumulation).

## Exports

All server-side. Identifiers accept a player source or character identifier (`LaborHandler` ones; `ModifyStatus` takes a source).

### ModifyStatus

```lua
---@param source number
---@param statusName string
---@param operation "Add"|"Remove"|"Set"
---@param value number
---@return boolean
exports['ls_statuses']:ModifyStatus(source, statusName, operation, value)
```

`false` on unknown `operation` or status. Protected statuses still reject the change.

```lua
-- Apply a ~15 min cooling buff (consumed via ls_inventory)
exports['ls_statuses']:ModifyStatus(source, 'cooled', 'Set', 100)
```

### GetLabor

```lua
---@param identifier number|string
---@return number|nil labor
---@return string|nil error  -- "labor_system_disabled" | "character_not_found"
exports['ls_statuses']:GetLabor(identifier)
```

### SetLabor / AddLabor / RemoveLabor

```lua
---@param identifier number|string
---@param amount number
---@return boolean success
---@return string|nil error
exports['ls_statuses']:SetLabor(identifier, amount)
exports['ls_statuses']:AddLabor(identifier, amount)
exports['ls_statuses']:RemoveLabor(identifier, amount)
```

Clamped to `[0, limit]`. `RemoveLabor` returns `false, "labor_already_at_minimum"` at 0; `AddLabor` returns `false, "labor_already_at_maximum"` at the limit.

```lua
exports['ls_statuses']:AddLabor(source, 100)
```

## Net Events

| Event | Args | Description |
|---|---|---|
| `Status:Server:Update` | `statusName: string, value: number, operation: string` | Client-initiated status change. `operation` is `"Add"`\|`"Remove"`\|`"Set"`. Rejected if the status is `protected` or unknown. |

## Config

`LaborConfig` (`configs/sh_labor.lua`):

```lua
---@class LaborConfig
---@field enabled boolean
---@field limit number
---@field increaseTime number    -- minutes between auto increases
---@field increaseOffline number -- labor granted per increaseTime while offline
---@field increase number        -- labor granted per increaseTime while online
```

## Types

```lua
---@class StatusData
---@field baseValue number|boolean
---@field icon string
---@field color string
---@field flash boolean
---@field modify? number          -- decay rate, units/minute
---@field options? StatusOptions

---@class StatusOptions
---@field noReset? boolean
---@field inverted? boolean
---@field hide? boolean
---@field order? number
---@field protected? boolean      -- rejects client-originated Status:Server:Update
```
