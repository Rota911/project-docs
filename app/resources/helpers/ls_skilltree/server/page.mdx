# Server

Server-authoritative skill trees. Resources define trees with nodes, prerequisites, and costs; players earn XP, level up, spend points to unlock nodes.

## Key concepts

- **SkillTree** — a named collection of nodes with configurable XP curve (`baseXp`, `xpGrowth`).
- **SkillNode** — a single ability/perk with a `cost` (points), optional `preRequisites`, `anyPreRequisites`, and `lock` lists.
- Character skills are stored in character data under `"skills"` as `{ [treeId] = TreeSkillData }`.
- `GetClass()` returns a `SkillTreeManagerProxy`; each tree is a `SkillTreeInstanceProxy`. Proxies wrap the live server-side objects through closures so methods survive the export boundary.

```lua
local ST = exports["ls_skilltree"]:GetClass()
local tree = ST:CreateAndRegister({
    id = "mining", name = "Mining", baseXp = 300, xpGrowth = 1.2,
    nodes = {
        basic_mining = { cost = 1, preRequisites = {} },
        advanced_mining = { cost = 2, preRequisites = { "basic_mining" } },
    }
})
```

> On startup, default trees from `Config.SkillTree` register first, then `Skilltree:RefreshSkilltrees` fires for external resources to register their own.
