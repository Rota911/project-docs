# ls_marker

DUI-based marker system rendering three world-space marker types (waypoint, ground, mark) via web textures on GTA sprites. Ground markers track vehicle wheel occupancy and sync state to workgroup/vehicle co-occupants through the server. All exports are client-side.

## Marker types

| Type | Description |
|------|-------------|
| `waypoint` | Floating direction indicator |
| `ground` | Parking/landing spot with vehicle-state colors |
| `mark` | Diamond icon/label marker |

## Mark

```lua
---@param data MarkerData
---@return string|nil id
exports.ls_marker:CreateMark(data)

---@param id string

exports.ls_marker:EnableMark(id)
exports.ls_marker:DisableMark(id)

---@param id string
---@param entity number
---@param offset? number
---@return boolean
exports.ls_marker:SetMarkEntity(id, entity, offset)

---@param id string
---@param pos vector3
---@return boolean
exports.ls_marker:SetMarkPosition(id, pos)

---@param id string
---@param key string
---@param value any
exports.ls_marker:PatchMarkSettings(id, key, value)
```

```lua
local id = exports.ls_marker:CreateGround({
    position = vector3(100.0, 200.0, 30.0),
    settings = {
        width = 17.2,
        height = 13.2,
        heading = 90.0,
        label = "Parking A",
        defaultBorderColor = "#e5e7eb",
        activeBorderColor = "#69db7c",
    },
    onVehicleParked = function(markerId, vehicle)

    end,
})
```

## MarkerData

```lua
---@class MarkerData
---@field type string set automatically by the export ("mark"|"ground"|"waypoint")
---@field position vector3|nil required unless `entity` is set
---@field entity number|nil attach marker to this entity handle
---@field entityOffset number|nil Z offset above entity (default 1.0)
---@field streamDistance number|nil render distance
---@field priority "high"|"medium"|"low"|nil render priority when cap reached (default "low")
---@field settings table|nil type-specific visual settings
---@field debug boolean|nil
---@field onVehicleParked fun(markerId: string, vehicle: number)|nil ground only
---@field onVehicleExited fun(markerId: string, vehicle: number)|nil ground only
---@field onVehicleParkConfirmed fun(markerId: string, vehicle: number)|nil ground only
---@field vehicleClass number|nil ground only, restrict to vehicle class
---@field models string[]|nil ground only, restrict to model names
```

> Render thread runs every 250ms, culls by visibility/distance, caps each type to 4 rendered instances sorted by priority.

## Events

### Client → Server

| Event | Args | Description |
|-------|------|-------------|
| `Marker:Server:Register` | `data: MarkerSyncState` | Registers a ground marker for syncing to workgroup/vehicle occupants. |
| `Marker:Server:Unregister` | `markerId: string` | Removes a ground marker from server sync state. |
| `Marker:Server:UpdateState` | `markerId, state, vehicleNetId?, borderColor?, backgroundColor?` | Updates marker state color, broadcasts to sync targets. |
| `Marker:Server:RequestMarkers` | `ownerSrc: number` | Requests all ground markers owned by `ownerSrc`. |
| `Marker:Server:RefreshTargets` | — | Re-pushes caller's markers to current sync targets. |
| `Marker:Server:VehicleEntered` | — | Pushes driver's markers to new passenger. |
| `Marker:Server:WorkgroupJoined` | — | Pushes all workgroup members' markers to joining player. |

### Server → Client

| Event | Payload | Description |
|-------|---------|-------------|
| `Marker:Client:Create` | `data: MarkerSyncState` | Creates a local copy of a synced ground marker. |
| `Marker:Client:StateUpdate` | `markerId, stateData` | `stateData`: `state`, `vehicleNetId`, `borderColor`, `backgroundColor`. |
| `Marker:Client:Remove` | `markerId: string` | Removes the local copy. |

### Local

| Event | Notes |
|-------|-------|
| `Marker:Client:MarkerDeleted` | Fires `Marker:Server:Unregister` for locally owned markers. |
| `Core:Client:CharacterLoaded` | Starts render + vehicle detection threads. |
| `Core:Client:EnterVehicle` | Triggers `Marker:Server:VehicleEntered`. |
| `Core:Client:ExitVehicle` / `Core:Client:BecameDriver` | Refreshes sync targets. |
| `Workgroups:Server:MemberAdded` / `MemberRemoved` | Server-side: pushes/removes markers between workgroup members. |
