# Server

## Notification

```lua
---@param source number
---@param data NotificationData
LS.UI:Notification(source, {
    title = 'Siker',
    message = 'Az akcio sikeresen vegzodott',
    type = 'success',
    duration = 3000
})
```

## InteractionNotification

Coroutine-blocking — yields until the player confirms/denies or `CloseInteractionNotification` is called.

```lua
---@param source number
---@param data InteractionNotificationData
---@return boolean|nil result
local accepted = LS.UI:InteractionNotification(source, {
    title = 'Robbery',
    message = 'Accept the robbery?',
    duration = 10000
})
```

Returns `false` immediately if an interaction prompt is already active for that player. Auto-resolves to `nil` on `playerDropped`.

## CloseInteractionNotification

```lua
---@param source number
LS.UI:CloseInteractionNotification(source)
```

## Events

### Server → Client

| Event | Payload |
|-------|---------|
| `UI:Client:Notification` | `NotificationData` — displays a toast notification |
| `UI:Client:InteractionNotification` | `InteractionNotificationData` — confirmation prompt; client resolves via `UI:Server:InteractionResult` |
| `UI:Client:CloseInteractionNotification` | _(none)_ — cancels any pending interaction prompt |
| `UI:Client:StartProgressBar` | `ProgressBarData` — starts the progress bar on the target client |
| `UI:Client:StopProgressBar` | _(none)_ — stops the active progress bar on the target client |

### Client → Server

| Event | Args |
|-------|------|
| `UI:Server:InteractionResult` | `result: boolean \| nil` — player's response to an interaction notification |
