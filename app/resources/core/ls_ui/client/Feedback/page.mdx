# Feedback

Notification, progress bar, text UI prompts, and screen fade. Access via `LS.UI`.

## Notification

```lua
---@param data NotificationData
LS.UI:Notification({
    title = 'Siker',
    message = 'Az akcio sikeresen vegzodott',
    type = 'success',
    duration = 3000
})
```

## Progressbar

```lua
---@param data ProgressBarData
---@return boolean started
LS.UI:Progressbar({
    tasks = {
        { name = 'Preparing', duration = 3000, anim = { dict = 'mini@repair', clip = 'fixing_a_player' } },
        { name = 'Finishing',  duration = 2000 }
    },
    disable = { move = true, combat = true }
})
```

Returns `false` if a bar is already active or `data` is invalid. Cancels automatically on death/ragdoll/swim unless `useWhileDead`/`allowRagdoll`/`allowSwimming` opt in.

## StopProgressBar / CancelProgress / IsProgressActive

```lua
LS.UI:StopProgressBar()      -- completes current bar, runs task callbacks
LS.UI:CancelProgress()       -- cancels current bar without completing
---@return boolean
LS.UI:IsProgressActive()
```

## TextUI

```lua
---@param data TextUIData | TextUIData[]
LS.UI:TextUI({
    id = 'lock',
    text = 'Lock vehicle',
    keyLabel = 'E',
    icon = 'lock'
})
```

## HideTextUI

```lua
---@param id string | string[]
LS.UI:HideTextUI('lock')
```

## PatchTextUI

```lua
---@param data TextUIPatchData
LS.UI:PatchTextUI({
    id = 'lock',
    text = 'Módosított szöveg'
})
```

## HideAllTextUIs

```lua
LS.UI:HideAllTextUIs()
```

## ScreenFadeOut

```lua
---@param duration? number
---@param headerMessage? string
LS.UI:ScreenFadeOut(1000, 'Betöltés...')
```

## ScreenFadeIn

```lua
---@param duration? number
LS.UI:ScreenFadeIn(1000)
```
