# ls_admin

In-game admin commands for player and world management, gated by rank via `LS:RegisterFunction` / `LS:Command`. No Lua exports — all functionality is chat commands.

> Player coords are saved to `Player(src).state.oldPosition` before any teleport so `/back` can restore them.

## Rank hierarchy

```lua
---@alias AdminRank string
---| "user"
---| "moderator"
---| "admin"
---| "headadmin"
---| "dev"
---| "owner"
```

Higher rank inherits lower-rank permissions (`RANK_ORDER` is ascending: `user=0` ... `owner=5`).

## IsAdmin

```lua
---@param source number
---@param minRank? string Default: 'admin'
---@return boolean
exports.ls_admin:IsAdmin(source, minRank)
```

Reads from server memory (`Private.Players`) — not spoofable. `source == 0` (console) always returns `true`.

## IsAdminOnDuty

```lua
---@param source number
---@param minRank? string Default: 'admin'
---@return boolean
exports.ls_admin:IsAdminOnDuty(source, minRank)
```

Same as `IsAdmin`, but also requires `player:GetDuty()` to be true.

## Commands

| Command | Aliases | Rank | Args | Description |
|---|---|---|---|---|
| `/back` | `tpback` | moderator | `[player]` | Restore previous position before last teleport |
| `/bring` | `br` | moderator | `[playerId]` | Teleport target to you |
| `/duty` | — | user | — | Toggle `player:SetDuty()` |
| `/freeze` | — | moderator | `[player]` | Freeze target's position |
| `/unfreeze` | — | moderator | `[player]` | Unfreeze target's position |
| `/goto` | `gt` | moderator | `<player> [target]` | Teleport to player (or teleport `target` to `player`) |
| `/kill` | `slay` | moderator | `[player]` | Set target health to 0 |
| `/logout` | — | moderator | `[playerSrc]` | Force-unload target's character |
| `/noclip` | `fly`, `nc` | moderator | — | Toggle noclip on self |
| `/setadmin` | — | headadmin | `<playerSrc> <group>` | Set target's admin group |
| `/tp` | `setcoords` | moderator | `<x y z [heading]>` or `vector3()/vector4()` | Teleport self to coords |
| `/tpm` | — | moderator | — | Teleport self to waypoint blip |
| `/visible` | — | moderator | `[playerSrc]` | Toggle entity visibility (vanish) |
| `/weather` | — | admin | — | Open `ls_weather` admin panel |

```
/tp 215.5 -810.2 30.7 180.0
/tp vector4(215.5, -810.2, 30.7, 180.0)
/goto 5 12
```

> `tpm` resolves via `LS.Callback('Admin:Client:Tpm', targetSrc)` — fails if the player has no waypoint or no ground is found under it.

## Events (Server → Client)

| Event | Payload | Description |
|---|---|---|
| `Admin:Client:KillPlayer` | — | Sets local ped health to 0 |
| `Admin:Client:ToggleNoclip` | — | Toggles noclip loop on target |
| `Admin:Client:SetVisible` | — | Toggles entity visibility + footstep audio |

No client → server events; all actions are initiated via server-side commands.

## Argument types

| Type | Description |
|---|---|
| `string` | Text argument |
| `number` | Numeric argument |
| `playerId` | Player ID, accepts `'me'` or a real server ID |
| `any` | Unvalidated |
