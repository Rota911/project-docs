# Characters — Server

No Lua exports. Single callback for character creation from the identity form.

## Identity:Server:CreateCharacter

```lua
---@param source number
---@param data CharacterCreateData
---@return boolean success
LS.Callback:Register('Identity:Server:CreateCharacter', function(source, data)
    local player = LS:GetPlayer(source)
    if not player then return false end

    return player:CreateCharacter(data)
end)
```

```lua
---@class CharacterCreateData
---@field first_name string
---@field middle_name string
---@field last_name string
---@field birth_date string
---@field gender string
```
