# ls_density

Manages GTA world population density (peds, vehicles, parked vehicles, scenarios) on the client. No public exports — controlled via `GlobalState.Population` and zone/schedule config.

## Density multipliers

Five float values (`0.0`-`1.0`) applied every frame via natives:

| Field | Native |
|-------|--------|
| `peds` | `SetPedDensityMultiplierThisFrame` |
| `vehicles` | `SetVehicleDensityMultiplierThisFrame` |
| `randomVehicles` | `SetRandomVehicleDensityMultiplierThisFrame` |
| `parked` | `SetParkedVehicleDensityMultiplierThisFrame` |
| `scenario` | `SetScenarioPedDensityMultiplierThisFrame` |

## Resolution order

1. `GlobalState.Population` — if set, used for all clients regardless of zone/schedule.
2. `Config.Zones[zoneName]` — looked up by the player's current GTA zone name.
3. `Config.Default` — time-scheduled fallback; each entry is `{ from, to, data }`, selected by current server clock hour.

A zone thread re-evaluates the active data block every 2 seconds; a separate thread applies the resolved multipliers every frame.

## GlobalState

```lua
---@class Population
---@field peds number
---@field vehicles number
---@field randomVehicles number
---@field parked number
---@field scenario number

---@type Population|nil
GlobalState.Population
```

`nil` means use zone/schedule defaults.

## Startup behavior

On resource start: disables wanted levels, random cop vehicle spawns, all dispatch services, a large list of ambient scenarios, and sets ambient gang relationship groups to "Respect" toward the player.

## Events

### Core:Client:CharacterLoaded

Starts the zone thread and density thread.

```lua
AddEventHandler("Core:Client:CharacterLoaded", function() end)
```

### onResourceStart

Restarts threads if the player is already logged in (resource restart).

## Admin Commands

```
setpop <peds> <vehicles> <randomVehicles> <parked> <scenario>  -- admin, sets GlobalState.Population
resetpop                                                        -- admin, clears GlobalState.Population
```

All `setpop` args are `number` in range `0.0`-`1.0`.

```
setpop 0.3 0.5 0.0 0.7 0.0
resetpop
```
