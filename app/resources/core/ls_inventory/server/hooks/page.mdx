# Hooks

Lets other resources intercept inventory actions **before** they commit. A hook can block the action (`return false`) or mutate data (`addItem` metadata). Follows the ox_inventory `registerHook` pattern.

## registerHook

```lua
---@alias HookEventType
---| "addItem"
---| "removeItem"
---| "moveItem"
---| "useItem"
---| "splitItem"
---| "clearInventory"

---@class HookOptions
---@field itemFilter? table<string, boolean>
---@field inventoryFilter? string[]
---@field print? boolean

---@param event HookEventType
---@param callback fun(payload: table): boolean|table|nil
---@param options? HookOptions
---@return number hookId
exports.ls_inventory:registerHook(event, callback, options)
```

## removeHooks

```lua
---@param hookId? number  -- nil removes all hooks owned by the calling resource
exports.ls_inventory:removeHooks(hookId)
```

```lua
local hookId = exports.ls_inventory:registerHook('addItem', function(payload)
    return false
end)

exports.ls_inventory:removeHooks(hookId)
exports.ls_inventory:removeHooks()  -- all hooks from this resource
```

> Hooks are automatically removed when the registering resource stops (`onResourceStop`).

## Event types

| Event | Fires before | Can block | Can mutate |
|---|---|---|---|
| `addItem` | item added | `return false` | `return metadata` |
| `removeItem` | item removed | `return false` | no |
| `moveItem` | item moved/transferred | `return false` | no |
| `useItem` | item used | `return false` | no |
| `splitItem` | stack split | `return false` | no |
| `clearInventory` | inventory cleared | `return false` | no |

## Filter options

| Option | Type | Effect |
|---|---|---|
| `itemFilter` | `table<string, boolean>` | only fires for the listed item names |
| `inventoryFilter` | `string[]` (Lua patterns) | only fires when `inventoryId` (or `targetInventoryId`/`sourceInventoryId` for moves) matches a pattern |
| `print` | `boolean` | logs every trigger: `[ls_inventory] Triggering hook "my_resource:addItem:1"` |

```lua
exports.ls_inventory:registerHook('moveItem', function(payload)
    return false
end, { inventoryFilter = { '^stash:' }, print = true })
```

## Payloads

### addItem

```lua
{
    characterId = "ABC123",
    inventoryId = "character:ABC123",
    itemName = "water",
    metadata = { expiresAt = 1700000000 },
    amount = 5
}
```

Return `false` to block, a `table` to replace `metadata` for the rest of the chain, or `nil`/`true` to allow unchanged.

```lua
exports.ls_inventory:registerHook('addItem', function(payload)
    if payload.itemName == 'contraband' then return false end
end)

exports.ls_inventory:registerHook('addItem', function(payload)
    payload.metadata.craftedAt = os.time()
    return payload.metadata
end, { itemFilter = { lockpick = true } })
```

### removeItem

Payload shape depends on the `filter` type passed to `RemoveItem`.

```lua
-- filter is a number (itemId) -> RemoveById
{
    characterId = "ABC123",
    inventoryId = "character:ABC123",
    itemId = 42,
    itemName = "water",
    metadata = { expiresAt = 1700000000 },
    amount = 1
}

-- filter is a string (itemName) -> RemoveByName
{
    characterId = "ABC123",
    itemName = "water",
    amount = 3
}
```

```lua
exports.ls_inventory:registerHook('removeItem', function(payload)
    if payload.itemName == 'quest_item' then return false end
end)
```

### moveItem

```lua
-- same-inventory move
{
    source = 1,
    characterId = "ABC123",
    inventoryId = "character:ABC123",
    itemId = 42,
    itemName = "water",
    metadata = {},
    fromX = 0, fromY = 0, toX = 3, toY = 2
}

-- cross-inventory move
{
    source = 1,
    characterId = "ABC123",
    sourceInventoryId = "character:ABC123",
    targetInventoryId = "stash:police_armory",
    itemId = 42,
    itemName = "weapon_pistol",
    metadata = {},
    fromX = 0, fromY = 0, toX = 5, toY = 3,
    isCrossInventory = true
}
```

```lua
exports.ls_inventory:registerHook('moveItem', function(payload)
    if payload.isCrossInventory and payload.itemName == 'soulbound_item' then
        return false
    end
end)
```

### useItem

```lua
{ characterId = "ABC123", itemId = 42, itemName = "medkit", metadata = { uses = 3 }, uses = 3 }
```

### splitItem

```lua
{
    source = 1,
    characterId = "ABC123",
    inventoryId = "character:ABC123",
    targetInventoryId = "pocket:ABC123",
    itemName = "ammo_pistol",
    metadata = {},
    splitAmount = 15,
    totalCount = 30
}
```

### clearInventory

```lua
{ characterId = "ABC123" }
```

```lua
exports.ls_inventory:registerHook('useItem', function(payload)
    if payload.uses and payload.uses <= 0 then return false end
end)

exports.ls_inventory:registerHook('clearInventory', function(payload)
    return false  -- block all clears
end)
```

## Notes

Hooks run in registration order; the first `false` return blocks the action and stops the chain. For `addItem`, a returned `metadata` table replaces the payload's metadata for subsequent hooks. An erroring hook is skipped (logged) without blocking the action. Hooks slower than 100ms log a warning.
