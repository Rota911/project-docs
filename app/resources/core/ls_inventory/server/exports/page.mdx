# Exports

Mutating exports return a `Result` table unless noted. `characterIdentifier` accepts a charId; `playerId`/`source` is a player server ID.

```lua
---@class Result
---@field ok boolean
---@field data? any
---@field msg? string
---@field msgTyp? "error"|"warning"
```

## Queries

| Export | Params | Returns |
|---|---|---|
| `GetPlayerInventory` | `playerId` | `PlayerInventoryInstance\|nil` |
| `GetInventory` | `inventoryId` | `InventoryInstance\|nil` |
| `GetInventoryItems` | `inventoryId` | `table<number, Item>` (raw rows) |
| `GetItem` | `characterIdentifier, itemName` | `Item\|nil` (raw row, not `ItemInstance`) |
| `HasItem` | `characterIdentifier, itemName, amount?` | `boolean` (default amount `1`) |
| `CanCarryAmount` | `inventoryId, itemName` | `boolean canCarry, number\|nil capacity` |
| `CanCarryItem` | `playerId, itemName, numberOfItems?` | `boolean` (default `1`) |

```lua
local stash = exports.ls_inventory:GetInventory('stash:police_armory')
if stash then stash:ForEach(function(item) print(item:GetName()) end) end
```

> Instance methods: [Instances](/resources/core/ls_inventory/server/instances)

## AddItem

```lua
---@param characterIdentifier string
---@param itemNameOrList string|string[]
---@param metadataOrUses? table|number
---@param usesOrAmount? number
---@param amount? number
---@param checkFit? boolean
---@return Result
exports.ls_inventory:AddItem(characterIdentifier, itemNameOrList, metadataOrUses, usesOrAmount, amount, checkFit)
```

```lua
local res = exports.ls_inventory:AddItem(charId, 'water', nil, nil, 5)
if res.ok then print(res.data.totalAdded) end

exports.ls_inventory:AddItem(charId, 'phone', { number = '555-1234' }, nil, 1)
```

> Hook: `addItem` runs before commit, see [Hooks](/resources/core/ls_inventory/server/hooks).

## RemoveItem

```lua
---@param characterIdentifier string
---@param filter number|string  -- itemId or itemName
---@param amount? number
---@param metadataMatch? table
---@param options? RemoveOptions
---@return Result
exports.ls_inventory:RemoveItem(characterIdentifier, filter, amount, metadataMatch, options)
```

`filter` as a `number` removes by itemId; as a `string` removes by itemName across all of the character's inventories.

```lua
exports.ls_inventory:RemoveItem(charId, 42, 1)            -- by itemId
exports.ls_inventory:RemoveItem(charId, 'water', 3)        -- by itemName
```

Result `data` for name-based removal: `{ itemsRemoved: number, clearedEquipmentSlots: table[] }`.

> Hook: `removeItem` runs before commit.

## AddItemOrDrop

Adds what fits; overflow is placed in a world drop at the character's feet.

```lua
---@param characterIdentifier string|number
---@param itemName string
---@param metadata? table
---@param uses? number
---@param amount? number
---@param dropOptions? DropOptions
---@return AddItemOrDropResult
exports.ls_inventory:AddItemOrDrop(characterIdentifier, itemName, metadata, uses, amount, dropOptions)
```

```lua
---@class AddItemOrDropResult
---@field ok boolean
---@field data? { totalAdded: number, totalRequested: number, overflow: number, addResult: table|nil, drop: table|nil, dropFailed: boolean }
---@field msg? string
```

```lua
local res = exports.ls_inventory:AddItemOrDrop(charId, 'water', nil, nil, 10)
if res.ok then
    print(res.data.totalAdded, res.data.overflow)
end
```

> Only accepts a single `itemName` string. `ok = false` if both the inventory and the drop fail (e.g. offline player).
> See [Drop System](/resources/core/ls_inventory/server/drops) for `DropOptions`.

## RegisterUsableItem / UnregisterUsableItem

```lua
---@alias UsableItemCallback fun(source: number, itemData: { itemId: number, itemName: string, metadata: table, inventoryId: string })

---@param itemName string
---@param callback UsableItemCallback
exports.ls_inventory:RegisterUsableItem(itemName, callback)

---@param itemName string
exports.ls_inventory:UnregisterUsableItem(itemName)
```

Runs server-side when the item is used (item must have `usable = true` in its definition). Registering twice for the same item overwrites the previous callback.

```lua
exports.ls_inventory:RegisterUsableItem('bandage', function(source, item)
    -- heal logic
end)
```

## GiveClothing

Adds a clothing item to the player's inventory and equips it.

```lua

---@param clothingData { type: string, index: number, value: number, texture: number }
---@param overrideItemName? string
---@return { success: boolean, reason?: string }
exports.ls_inventory:GiveClothing(playerId, clothingData, overrideItemName)
```
