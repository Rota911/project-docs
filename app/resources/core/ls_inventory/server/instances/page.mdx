# Instances

OOP wrappers over the inventory services. Three types:

- **PlayerInventoryInstance** — all of a character's inventories (character, pocket, backpack)
- **InventoryInstance** — a single inventory
- **ItemInstance** — a single item

## PlayerInventoryInstance

```lua
---@param playerId number
---@return PlayerInventoryInstance|nil
exports.ls_inventory:GetPlayerInventory(playerId)
```

| Method | Returns | Notes |
|---|---|---|
| `GetCharacterIdentifier()` | `string` | |
| `GetInventoryIds()` | `{ id, type, label }[]` | e.g. `"character:ABC123"`, type `"character"` |
| `GetInventory(inventoryType?)` | `InventoryInstance\|nil` | default type `"character"` |
| `GetAllInventories()` | `table<string, InventoryInstance>` | keyed by type |
| `GetItems(category?)` | `table<number, ItemInstance>` | merged across inventories |
| `GetItem(itemName)` | `ItemInstance\|nil` | first match |
| `GetItemById(itemId)` | `ItemInstance\|nil` | |
| `HasItem(itemName, amount?)` | `boolean` | default amount `1` |
| `CountItem(itemName)` | `number` | total across inventories |
| `CanCarryAmount(itemName)` | `boolean, number` | canCarry, totalCapacity |
| `AddItem(itemName, metadata?, uses?, amount?)` | `Result` | default amount `1` |
| `RemoveItem(filter, amount?, metadataMatch?, options?)` | `Result` | see below |
| `Clear()` | `Result` (`data.itemsCleared`) | |
| `GetItemCount()` / `GetTotalWeight()` | `number` | |
| `IsEmpty()` | `boolean` | |
| `GetItemsByFlag(flag)` / `GetItemsByName(itemName)` | `table<number, ItemInstance>` | |
| `GetExpiredItems()` / `GetDepletedItems()` | `table<number, ItemInstance>` | |
| `RemoveExpiredItems()` / `RemoveDepletedItems()` | `number` removed | |
| `Filter(cb)` / `Find(cb)` / `ForEach(cb)` | varies | `cb: fun(item): boolean` |
| `Serialize()` | `table` | `{ characterIdentifier, inventories, itemCount, totalWeight }` |

`RemoveItem`'s `filter` is a `number` (itemId) or `string` (itemName, searched across all of the player's inventories). There is no separate `RemoveItemByName`.

```lua
local inv = exports.ls_inventory:GetPlayerInventory(source)
inv:RemoveItem(42, 1)         -- by itemId
inv:RemoveItem('water', 3)    -- by itemName, data: { itemsRemoved }

local heavyItems = inv:Filter(function(item) return item:GetWeight() > 1000 end)
```

## InventoryInstance

Same method surface as `PlayerInventoryInstance` but scoped to one inventory.

```lua
---@param inventoryId string
---@return InventoryInstance|nil
exports.ls_inventory:GetInventory(inventoryId)
```

| Method | Returns |
|---|---|
| `GetId()` / `GetCharacterIdentifier()` | `string` |
| `GetItems(category?)` | `table<number, ItemInstance>` |
| `GetItem(itemName)` / `GetItemById(itemId)` | `ItemInstance\|nil` |
| `HasItem(itemName, amount?)` | `boolean` |
| `CountItem(itemName)` | `number` |
| `CanCarryAmount(itemName)` | `boolean, number\|nil` |
| `AddItem(itemName, metadata?, uses?, amount?)` | `Result` |
| `RemoveItem(filter, amount?, metadataMatch?, options?)` | `Result` |
| `Clear()` | `Result` |
| `GetItemCount()` / `GetTotalWeight()` | `number` |
| `IsEmpty()` | `boolean` |
| `GetItemsByFlag(flag)` / `GetItemsByName(itemName)` | `table<number, ItemInstance>` |
| `GetExpiredItems()` / `GetDepletedItems()` | `table<number, ItemInstance>` |
| `RemoveExpiredItems()` / `RemoveDepletedItems()` | `number` |
| `Filter(cb)` / `Find(cb)` / `ForEach(cb)` | varies |
| `Serialize()` | `table` |

```lua
local stashInv = exports.ls_inventory:GetInventory('stash:police_armory')
if stashInv then
    stashInv:ForEach(function(item) print(item:GetName(), item:GetCount()) end)
end
```

## ItemInstance

```lua
---@class ItemInstance
---@field itemId number
---@field itemName string
---@field inventoryId string
---@field metadata table
---@field uses number|nil
---@field count number
```

Obtained via `inventory:GetItem()` / `inventory:GetItemById()`.

| Method | Returns | Notes |
|---|---|---|
| `GetId()` / `GetName()` / `GetInventoryId()` | `number` / `string` / `string` | |
| `GetLabel()` / `GetDescription()` | `string\|nil` | from item definition |
| `GetCategoryName()` / `GetCategory(category)` | `string\|nil` / `boolean` | |
| `GetCount()` | `number` | |
| `GetMetadata()` / `GetMetadataValue(key)` | `table` / `any` | |
| `SetMetadataValue(key, value)` | `Result` | persists immediately |
| `GetDefinition()` | `table\|nil` | |
| `GetWeight()` / `GetUnitWeight()` | `number` | total / per-unit |
| `GetUses()` | `number\|nil` | nil if item has no uses system |
| `GetMaxStack()` / `IsStackable()` | `number` / `boolean` | |
| `IsUnique()` | `boolean` | true unless `itemDef.isUnique == false` |
| `IsUsable()` | `boolean` | `itemDef.usable == true` |
| `CanDrop()` | `boolean` | false only if `itemDef.canDrop == false` |
| `HasFlag(flag)` | `boolean` | |
| `IsDepleted()` | `boolean` | `uses ~= nil and uses <= 0` |
| `IsExpired()` | `boolean` | `metadata.expiresAt < os.time()` |
| `GetExpiresAt()` / `GetTimeUntilExpiry()` | `number\|nil` | seconds left, `0` if expired |
| `Remove(amount?)` | `Result` | |
| `MoveToInventory(targetInventoryId)` | `Result` | removes from source, re-adds to target |
| `Use()` | `Result` (`data.consumed: boolean`) | decrements `uses`, removes if depleted |
| `Serialize()` | `table` | `{ itemId, itemName, inventoryId, metadata, uses, count }` |

```lua
local item = inventory:GetItem('medkit')
if item and item:IsUsable() and not item:IsDepleted() then
    local result = item:Use()
    if result.ok and result.data.consumed then
        print('medkit consumed')
    end
end
```
