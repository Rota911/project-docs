# Client

## Exports

### GetItem

Item definition from the local cache.

```lua
---@param itemName string
---@return table|nil
exports.ls_inventory:GetItem(itemName)
```

```lua
local def = exports.ls_inventory:GetItem('water')
if def then print(def.label, def.weight, def.category) end
```

### GetItems

All cached item definitions.

```lua
---@return table<string, table>
exports.ls_inventory:GetItems()
```

### OpenInventory

```lua
---@param invType? "player"|"stash"|"trunk"|"glovebox"
---@param data? string|number|table  -- stash id string; vehicle { netid: number } or plain netid number
exports.ls_inventory:OpenInventory(invType, data)
```

```lua
exports.ls_inventory:OpenInventory('stash', 'town_storage')
exports.ls_inventory:OpenInventory()  -- player inventory
```

### CloseInventory

```lua
exports.ls_inventory:CloseInventory()
```

### IsInventoryOpen

```lua
---@return boolean
exports.ls_inventory:IsInventoryOpen()
```

### IsInventoryLocked

```lua
---@return boolean
exports.ls_inventory:IsInventoryLocked()
```

Backed by `LocalPlayer.state.lockInventory`.

### EquipItem / UnequipItem

```lua
---@param itemId number
---@param itemName string
---@param metadata table|nil
---@param inventoryId string|nil
exports.ls_inventory:EquipItem(itemId, itemName, metadata, inventoryId)

exports.ls_inventory:UnequipItem()
```

### HasItemInHand / GetItemInHand

```lua
---@return boolean
exports.ls_inventory:HasItemInHand()

---@return table|nil  -- { itemId, itemName, metadata, inventoryId }
exports.ls_inventory:GetItemInHand()
```

```lua
local item = exports.ls_inventory:GetItemInHand()
if item then print(("in hand: %s (id %d)"):format(item.itemName, item.itemId)) end
```

### GetDropsNearby

All active drops within `Config.DropSystem.LoadDistance` of the player.

```lua
---@return DropClientData[]|false
exports.ls_inventory:GetDropsNearby()
```

### GetDropAtCoord

```lua
---@param coords vector3
---@param radius number
---@return DropClientData[]|false
exports.ls_inventory:GetDropAtCoord(coords, radius)
```

```lua
local coords = GetEntityCoords(cache.ped)
local drops = exports.ls_inventory:GetDropAtCoord(coords, 5.0)
if drops then
    for _, drop in ipairs(drops) do
        print(drop.dropId, #(coords - drop.coords))
    end
end
```

> Full drop reference: [Drop System](/resources/core/ls_inventory/server/drops)

## Net events (server -> client)

These are pushed automatically by the server; you normally just listen, not trigger.

| Event | Args | Description |
|---|---|---|
| `Inventory:Client:RefreshInventory` | – | Re-pull inventory after a server-side change |
| `Inventory:Client:CacheItems` | `items` | Push full item-definition cache |
| `Inventory:Client:OpenInventory` / `CloseInventory` | `data` / – | Open/close the NUI |
| `Inventory:Client:ClearExternalInventory` | `inventoryId` | Close a specific stash/drop view |
| `Inventory:Client:EquipItem` | `data` | Force-equip an item |
| `Inventory:Client:EquipItemFromInventory` | `data` | Equip from inventory UI (closes inventory first) |
| `Inventory:Client:ItemConsumed` | `data` | Drop item from hand if it was consumed |
| `Inventory:Client:ConsumeFeedback` | `consume` | Cosmetic progress bar/animation for item use |
| `Inventory:Client:ApplyEquippedClothing` | `clothingAppearances` | Apply equipped clothing to local ped |
| `Inventory:Client:WeaponSlotCleared` | `{ slotType, itemName }` | Equipment slot cleared |
| `Inventory:Client:WeaponCleanup` | – | Clear weapon state |
| `Inventory:Client:StashLockedSlots` | `data` | Push locked-slot info to the NUI |

```lua
AddEventHandler('Inventory:Client:RefreshInventory', function()
    -- contents changed server-side
end)
```

> Full server event/hook reference: [Events](/resources/core/ls_inventory/server/events), [Hooks](/resources/core/ls_inventory/server/hooks)
