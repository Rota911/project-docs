# Appearance — Client

Ped model, head blend, face structure, head overlays, drawables, and props. Access via `exports.ls_appearance`.

## OpenAppearanceMenu

```lua
---@param type string "character_creator" | "admin_creator" | shop type
---@param structure table? Category list override; nil uses config default for `type`
---@param callback fun(ok: boolean, appearance: table)? Called when editor closes
---@param ped number? Defaults to cache.ped
---@param save boolean? Whether saving is enabled in the UI, default true
exports.ls_appearance:OpenAppearanceMenu(type, structure, callback, ped, save)
```

```lua
exports.ls_appearance:OpenAppearanceMenu("character_creator", nil, function(ok, appearance)
    if ok then LS.Logger:Debug("Appearance saved") end
end)
```

## Events

| Event | Direction | Payload | Description |
|---|---|---|---|
| `Appearance:Client:OpenAppearance` | Server → Client | `type, structure?` | Opens editor on target client, sent by `/appearance` admin command |
| `Appearance:Client:AppearanceLoaded` | Local | `appearanceData: table\|nil` | Fired after saved skin applied to local ped on login / resource start |
