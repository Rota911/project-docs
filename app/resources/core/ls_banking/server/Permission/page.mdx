# Permission

Account permission management for members.

```lua
local PermissionService = require 'core.permission'
```

## HasPermission

```lua
---@param accountId number
---@param charId number
---@param permission BankPermission
---@return boolean
PermissionService:HasPermission(accountId, charId, permission)
```

```lua
---@alias BankPermission 'view' | 'deposit' | 'withdraw' | 'transfer' | 'manage_cards' | 'manage_members' | 'close'
```

```lua
if PermissionService:HasPermission(5, 123, 'withdraw') then
    print('User can withdraw')
end
```

## Grant

```lua
---@param accountId number
---@param charId number
---@param permission BankPermission
---@param grantedBy? number
---@return boolean success
---@return string? error
PermissionService:Grant(accountId, charId, permission, grantedBy)
```

```lua
PermissionService:Grant(5, 456, 'deposit', 123)
```

## GetMembers

```lua
---@param accountId number
---@return BankAccountMember[]
PermissionService:GetMembers(accountId)
```

```lua
local members = PermissionService:GetMembers(5)
for i = 1, #members do
    print(members[i].charId, #members[i].permissions)
end
```

## GetAllPermissionTypes

```lua
---@return BankPermission[]
PermissionService:GetAllPermissionTypes()
```

Returns all available permission types.

## Permissions

| Permission | Description |
|---|---|
| `view` | View account details |
| `deposit` | Deposit funds |
| `withdraw` | Withdraw funds |
| `transfer` | Transfer to other accounts |
| `manage_cards` | Create and manage cards |
| `manage_members` | Add/remove members and permissions |
| `close` | Close the account |

> Account owners have all permissions by default.
