# Transaction

Transaction processing for all account operations.

```lua
local TransactionService = require 'core.transaction'
```

## Deposit

```lua
---@param accountId number
---@param amount number
---@param charId number
---@param reason? string
---@param metadata? table
---@return boolean success
---@return string? error
TransactionService:Deposit(accountId, amount, charId, reason, metadata)
```

```lua
TransactionService:Deposit(5, 10000, 123, 'Cash deposit')
```
