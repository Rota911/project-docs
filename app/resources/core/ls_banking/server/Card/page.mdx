# Card

Card issuance and management.

```lua
local CardService = require 'core.card'
```

## Create

```lua
---@param params BankCardCreateParams
---@return BankCard? card
---@return string? error
CardService:Create(params)
```

```lua
---@class BankCardCreateParams
---@field accountId number
---@field holderCharId number
---@field type? BankCardType
---@field dailyLimit? number
```

```lua
local card, err = CardService:Create({
    accountId = 5,
    holderCharId = 123,
    type = 'debit'
})
```

## Get

```lua
---@param cardId number

CardService:Get(cardId)
```


## Block

```lua
---@param cardId number
---@param reason? string
---@return boolean success
---@return string? error
CardService:Block(cardId, reason)
```

```lua
CardService:Block(10, 'Lost card')
```

## Unblock

```lua
---@param cardId number
---@return boolean success
---@return string? error
CardService:Unblock(cardId)
```

```lua
---@param cardId number
```

## SetPin

```lua
---@param cardId number
---@param newPin string
---@return boolean success
---@return string? error
CardService:SetPin(cardId, newPin)
```

> PIN must be 4 digits.

```lua
CardService:SetPin(10, '1234')
```

```lua
---@param cardId number
```
