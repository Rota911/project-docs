# Billing

Bill creation and payment processing.

```lua
local BillingService = require 'modules.billing.service'
```

## Create

```lua
---@param toCharId number
---@param issuer BillIssuer
---@param data BillCreateData
---@return Bill? bill
---@return string? error
BillingService:Create(toCharId, issuer, data)
```

```lua
---@class BillIssuer
---@field type 'job' | 'faction' | 'player'
---@field identifier string|number
---@field label? string

---@class BillCreateData
---@field amount number
---@field description? string
---@field dueAt? string
---@field metadata? table
```

```lua
local bill, err = BillingService:Create(123, {
    type = 'job',
    identifier = 'police',
    label = 'LSPD'
}, {
    amount = 5000,
    description = 'Speeding ticket'
})
```

## Get

```lua
---@param billId number
---@return Bill?
BillingService:Get(billId)
```

## GetByChar

```lua
---@param charId number
---@param filter? BillFilter
---@return Bill[]
BillingService:GetByChar(charId, filter)
```

```lua
---@class BillFilter
---@field status? 'active' | 'paid' | 'overdue' | 'cancelled'
---@field limit? number
```

```lua
local active = BillingService:GetByChar(123, { status = 'active' })
```

## Cancel

```lua
---@param billId number
---@return boolean success
---@return string? error
BillingService:Cancel(billId)
```

## Pay

```lua
---@param charId number
---@param billId number
---@param amount? number
---@return boolean success
---@return string? error
BillingService:Pay(charId, billId, amount)
```

Pays from character's personal account.

```lua
BillingService:Pay(123, 5, 2500)
```

## Exports

All exports are `exports['ls_banking']:Name(...)`, `toPlayer`/`playerId` accepts source, charId, or identifier.

| Export | Params | Returns |
|---|---|---|
| `CreateBill` | `toPlayer, issuer: BillIssuer, data: BillCreateData` | `Bill?, error?` |
| `GetBill` | `billId` | `Bill?` |
| `GetPlayerBills` | `playerId, filter?: BillFilter` | `Bill[]` |
| `PayBill` | `playerId, billId, amount?` | `success, error?` |
| `CancelBill` | `billId` | `success, error?` |
| `GetTotalOutstanding` | `playerId` | `number` |
| `GetBillHistory` | `playerId, limit?` | `Bill[]` |

```lua
local bill, err = exports['ls_banking']:CreateBill(source,
    { type = 'job', identifier = 'mechanic', label = 'LS Customs' },
    { amount = 15000, description = 'Vehicle repair' })
```

> Overdue bills from jobs/factions trigger forced collection from personal account.
