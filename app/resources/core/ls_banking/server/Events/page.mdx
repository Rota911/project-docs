# Events

Banking system events for monitoring and integration. Access via `LS.Banking` exports or the internal `EventBus`.

## BankEventPayload

```lua
---@class BankEventPayload
---@field eventType BankEventType
---@field accountId number?
---@field charId number?
---@field data table -- event-specific fields
---@field timestamp number -- os.time()
```

## Listening to Events

```lua
local EventBus = require 'core.events'

---@param eventType BankEventType
---@param handler fun(payload: BankEventPayload)
---@return number listenerId
EventBus:On(eventType, handler)
```

```lua
EventBus:On('account_created', function(payload)
    print('New account:', payload.data.accountNumber)
end)
```

Other resources should use the exported equivalent instead of `require`:

```lua
exports.ls_banking:OnBankEvent('transaction', function(payload)
    print(payload.accountId, payload.data.amount)
end)
```

## Middleware

```lua
---@param eventType BankEventType
---@param handler fun(payload: BankEventPayload): boolean? -- return false to block
---@return number middlewareId
EventBus:Use(eventType, handler)
```

```lua
exports.ls_banking:UseBankMiddleware('withdraw', function(payload)
    if isFrozen(payload.accountId) then return false end
end)
```

## Other EventBus methods

```lua
---@param eventType BankEventType
---@param listenerId number
EventBus:Off(eventType, listenerId)

---@param eventType BankEventType
---@return number
EventBus:ListenerCount(eventType)
```

> Every emit also fires standard event `Banking:<eventType>` via `TriggerEvent`, carrying the same `BankEventPayload`.

## Account Events

| Event | `data` fields | Description |
|---|---|---|
| `account_created` | `accountId, accountNumber, type, ownerCharId` | New account created |
| `account_locked` | `accountId, previousStatus, newStatus, reason` | Account locked/frozen |
| `account_unlocked` | `accountId, previousStatus, newStatus, reason` | Account unlocked |
| `account_closed` | `accountId, previousStatus, newStatus, reason` | Account closed |

```lua
AddEventHandler('Banking:account_created', function(payload)
    print(('Account %s created for char %d'):format(payload.data.accountNumber, payload.charId))
end)
```

## Card Events

| Event | `data` fields | Description |
|---|---|---|
| `card_created` | `cardId, accountId, holderCharId, cardType` | New card issued |
| `card_blocked` | `cardId, reason, previousStatus` | Card blocked/stolen |
| `card_unblocked` | `cardId` | Card unblocked |

## Transaction Events

| Event | `data` fields | Description |
|---|---|---|
| `transaction` | `transactionId, type, amount, balanceAfter, reason?, metadata?` (transfers add `fromAccountId, toAccountId, fromBalanceAfter, toBalanceAfter`) | Transaction processed |

```lua
AddEventHandler('Banking:transaction', function(payload)
    print(payload.accountId, payload.data.type, payload.data.amount)
end)
```

## Loan Events

| Event | `data` fields | Description |
|---|---|---|
| `loan_created` | `loanId, charId, accountId, principal, total, tier, assetType, assetId` | Loan approved |
| `loan_payment` | `loanId, charId, accountId, payAmount, remainingBalance` | Loan payment made |
| `loan_paid_off` | `loanId, charId, accountId` | Loan fully paid |
| `loan_overdue` | `loanId, charId, accountId` | Loan payment overdue |

## Permission Events

| Event | `data` fields | Description |
|---|---|---|
| `permission_changed` | `action ('grant'\|'revoke'), permission, targetCharId, grantedBy?, revokedBy?` | Permission granted/revoked |

## Billing Events

| Event | Parameters | Description |
|---|---|---|
| `Billing:OnBillCreated` | `billData` | Bill created |
| `Billing:OnBillPaid` | `billData, payAmount` | Bill payment processed |
| `Billing:OnBillCancelled` | `billData` | Bill cancelled |
| `Billing:OnBillOverdue` | `billData, collected` | Bill marked overdue (`collected` = forced amount taken, 0 if none) |

```lua
AddEventHandler('Billing:OnBillCreated', function(billData)
    print(('Bill %d created for char %d: %s'):format(
        billData.billId, 
        billData.toCharId, 
        billData.amount
    ))
end)
```

> Billing events use standard FiveM `AddEventHandler`, not EventBus.
