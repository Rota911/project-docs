# Logger

Single Logger instance shared across all resources. KVP-persisted, auto-syncs between server/client.

## Basic Usage

```lua
LS.Logger:Info("message")
LS.Logger:Error("message")
LS.Logger:Success("message")
LS.Logger:Warn("message")
LS.Logger:Debug("message")  -- only when sv_environment = "DEV"
```

Tables auto-serialize. Methods return `self` for chaining.

## SetDefaults() - Use This

Set once in a `shared_script`, applies to all logs in that resource:

```lua
-- shared/logger_config.lua
LS.Logger:SetDefaults({
    prefixes = { "INVENTORY" },
    id = "inventory"
})

-- Now everywhere in your resource:
LS.Logger:Info("Item added")  
-- Output: [INFO] [INVENTORY] Item added
```

Both server and client get the same defaults.

## Override Per-Call

```lua
LS.Logger:Debug("Special case", {
    settings = {
        prefixes = { "INVENTORY", "SPECIAL" },
        subPrefix = "VALIDATION",
        id = "inventory_special"
    }
})
```

Priority: Explicit settings > SetDefaults() > no settings

## Settings Object

```lua
---@class LoggerLSettings
---@field prefixes string[]?
---@field subPrefix string?
---@field id string?  -- for suppression
```

## Commands

All work from server console or F8. Auto-sync everywhere.

```
logger:suppress <id> [state]           -- Suppress by ID
logger:unsuppress <id>                 -- Unsuppress by ID
logger:toggle <resource> <state>       -- Enable/disable resource
logger:mute <resource> <level> [state] -- Mute specific level (debug/info/warn/error/success)
logger:reset                           -- Clear all KVP
logger:list                            -- Show all suppressions & configs
logger:status [resource]               -- Show resource status
```

Examples:
```
logger:suppress inventory_debug true
logger:toggle ls_inventory false
logger:mute ls_inventory debug true
```

## Key Methods

```lua
---@param settings LoggerLSettings
LS.Logger:SetDefaults(settings)

---@param id string
---@param suppress boolean
LS.Logger:SuppressId(id, suppress)

---@param resourceName string
---@param enabled boolean
LS.Logger:SetEnabled(resourceName, enabled)

---@param resourceName string
---@param level logLevel  -- "info"|"error"|"success"|"warn"|"debug"
---@param muted boolean
LS.Logger:SetLevelMuted(resourceName, level, muted)
```

## KVP Persistence

All settings (suppressions, configs, mutes) save to KVP automatically. Persist across restarts.

## Examples

### Simple Resource
```lua
-- shared.lua
LS.Logger:SetDefaults({
    prefixes = { "BANKING" },
    id = "banking"
})

-- server/main.lua
LS.Logger:Info("Account created")
LS.Logger:Debug("Balance updated")
```

### With Subsystems
```lua
-- shared.lua
LS.Logger:SetDefaults({
    prefixes = { "JOBS" }
})

-- server/salary.lua
LS.Logger:Info("Salary paid", {
    settings = {
        subPrefix = "SALARY",
        id = "salary_log"
    }
})
-- Output: [INFO] [JOBS] [SALARY] Salary paid
```

### Different Server/Client Defaults
```lua
-- shared.lua
if IsDuplicityVersion() then
    LS.Logger:SetDefaults({ prefixes = { "INV", "SV" } })
else
    LS.Logger:SetDefaults({ prefixes = { "INV", "CL" } })
end
```

## Don't Do

- ❌ `_G.LogSettings` - doesn't work, use `SetDefaults()`
- ❌ Hardcode settings in every call
- ❌ Log sensitive data (passwords, keys)
