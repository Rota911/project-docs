# RPC

Bidirectional, typed communication layer between **NUI (React)**, **Lua client**, and **Lua server**. Replaces raw `SendNUIMessage` / `RegisterNUICallback` / `TriggerServerEvent` with a structured call/response system backed by a nonce-based security layer.

> Package: [`@matehun/rpc`](https://www.npmjs.com/package/@matehun/rpc)
>
> ```
> bun add @matehun/rpc
> ```

---

## Communication Paths

| # | From | To | Method |
|---|------|----|--------|
| 1 | NUI | Client | `rpc.call()` → `Rpc:Register()` |
| 2 | Client | NUI | `Rpc:Send()` → `useNuiEvent()` |
| 3 | Client | NUI (await) | `Rpc:Call()` |
| 4 | Client | Server (await) | `Rpc:CallServer()` |
| 5 | Client | Server (fire) | `Rpc:TriggerServer()` |
| 6 | NUI | Server (via proxy) | `rpc.callServer()` → `Rpc:RegisterServerEvent()` |
| 7 | Server | Client NUI | `Rpc:Send(src)` → `useNuiEvent()` |
| 8 | Server | All NUIs | `Rpc:SendAll()` → `useNuiEvent()` |
| 9 | Server | Client (await) | `Rpc:Call(src)` → `Rpc:RegisterHandler()` |

Access the module via `LS.rpc` on both client and server.

---

## Lua — Client

### `Rpc:Register(route, handler)`

Registers a **NUI-callable** handler. When NUI calls `rpc.call(route, payload)` it hits this. Also handles the `callServer` proxy under the hood.

```lua
---@param route string
---@param handler fun(data: table): any
Rpc:Register('getVehicleSpeed', function(data)
    local vehicle = GetVehiclePedIsIn(PlayerPedId(), false)
    if not DoesEntityExist(vehicle) then error('Not in a vehicle') end
    return { kmh = math.floor(GetEntitySpeed(vehicle) * 3.6) }
end)
```

### `Rpc:RegisterHandler(route, handler)`

Registers a **server-callable** handler. Server uses `Rpc:Call(src, route)` to invoke this and await its return value.

```lua
---@param route string
---@param handler fun(data: table): any
Rpc:RegisterHandler('getClientPosition', function(data)
    local coords = GetEntityCoords(PlayerPedId())
    return { x = coords.x, y = coords.y, z = coords.z }
end)
```

### `Rpc:Send(action, data)`

Pushes a message to NUI. Fire-and-forget — no response. NUI listens with `useNuiEvent`.

```lua
---@param action string
---@param data? table
Rpc:Send('updateHud', { health = 80, armour = 50 })
```

### `Rpc:Call(action, data, timeout)`

Sends a message to NUI and **awaits** a response back. NUI must post back to `__rpc:response` using the `__rpcId` it receives.

```lua
---@param action string
---@param data? table
---@param timeout? number
---@return any
local result = Rpc:Call('getCurrentFormData', { form = 'characterCreator' }, 8000)
```

### `Rpc:CallServer(route, data, timeout)`

Calls a **server-side** `Rpc:RegisterServerEvent` handler and **awaits** the response. Always wrap in `pcall` to handle network or handler errors.

```lua
---@param route string
---@param data? table
---@param timeout? number
---@return any
local ok, result = pcall(function()
    return Rpc:CallServer('getPlayerInfo', {})
end)
```

### `Rpc:TriggerServer(route, data)`

Fires to a server handler with **no response**. The server-side handler receives `id = nil`, so no result is ever sent back. Acquires a nonce automatically before firing.

```lua
---@param route string
---@param data? table
Rpc:TriggerServer('logAction', { action = 'openedShop', meta = { shop = 'ammunition' } })
```

> **Deprecated alias:** `Rpc:SendServer()` still works but will be removed in a future release. Migrate to `Rpc:TriggerServer()`.

## Lua — Server

### `Rpc:RegisterServerEvent(route, handler, config?)`

Registers a handler that clients (via `Rpc:CallServer` / `Rpc:TriggerServer`) or NUI (via `rpc.callServer` proxy) can invoke. The first argument is always the player `source`. Accepts an optional [`RpcRouteConfig`](#rpcrouteconfig) for rate limiting, auth, and validation.

```lua
---@param route string
---@param handler fun(source: number, data: table): any
---@param config? RpcRouteConfig
Rpc:RegisterServerEvent('getPlayerInfo', function(src, data)
    return {
        name   = GetPlayerName(src),
        source = src,
        ping   = GetPlayerPing(src),
    }
end)
```

With full config:

```lua
Rpc:RegisterServerEvent('completeJob', function(src, data)
    return handleComplete(src, data.sessionId)
end, {
    rate = { limit = 3, window = 30000 },
    auth = function(src)
        if not LS:GetCharacter(src) then
            return false, 'not authenticated'
        end
        return true
    end,
    validator = function(data)
        if type(data.sessionId) ~= 'string' or #data.sessionId < 1 then
            return false, 'sessionId must be a non-empty string'
        end
        return true
    end,
})
```

Errors thrown inside the handler are caught automatically and returned to the caller as `{ success = false, data = "<message>" }`.

> **Deprecated alias:** `Rpc:Register()` still works on the server but will be removed in a future release. Migrate to `Rpc:RegisterServerEvent()`.

---

### `RpcRouteConfig`

Optional configuration table passed as the third argument to `Rpc:RegisterServerEvent`.

```lua
---@class RpcRouteConfig
---@field auth?      fun(source: number): boolean, string?
---@field rate?      RpcRateConfig
---@field validator? fun(data: table): boolean, string?

---@class RpcRateConfig
---@field limit  number
---@field window number
```

| Field | Type | Description |
|-------|------|-------------|
| `auth` | `fun(src): boolean, string?` | Called before the handler. Return `false, reason` to reject with a security strike. |
| `rate` | `{ limit: number, window: number }` | Max `limit` calls within `window` ms per player. Excess calls are rejected and strike the player. |
| `validator` | `fun(data): boolean, string?` | Validates the incoming payload. Return `false, reason` to reject cleanly without a security strike. |

All three checks run **after** nonce validation and **before** the handler. Execution order: `nonce → rate → auth → validator → handler`.

---

### `Rpc:Send(source, action, data)`

Pushes a message to **one** client's NUI. NUI listens with `useNuiEvent`.

```lua
---@param source number
---@param action string
---@param data? table
Rpc:Send(src, 'notification', { type = 'success', message = 'Welcome!' })
```

### `Rpc:SendAll(action, data)`

Broadcasts a message to **every** client's NUI.

```lua
---@param action string
---@param data? table
Rpc:SendAll('serverAnnouncement', { message = 'Restart in 5 minutes.' })
```

### `Rpc:Call(source, route, data, timeout)`

Calls a **client-side** `Rpc:RegisterHandler` handler and **awaits** the response. Validates the player exists before sending.

```lua
---@param source number
---@param route string
---@param data? table
---@param timeout? number
---@return any
local ok, result = pcall(function()
    return Rpc:Call(targetSrc, 'getClientPosition', {}, 5000)
end)
```

## Security

Every client-to-server call goes through a **nonce handshake** before the payload reaches the handler.

```
Client                          Server
  │── NONCE_REQ(reqId, route) ──►│  validate route exists, rate-limit nonce req
  │◄── NONCE_RES(reqId, nonce) ──│  issue nonce tied to (src, route, ttl=8s)
  │── C2S_REQ(id, route, data, nonce) ──►│  validate nonce src/route/expiry, then run handler
```

| Protection | Detail |
|------------|--------|
| Nonce TTL | 8 000 ms — expired nonces are rejected |
| Single-use | Nonce is consumed on first use; replay is impossible |
| Route binding | Nonce issued for route A cannot be spent on route B |
| Source binding | Nonce issued for player A cannot be used by player B |
| Pool cap | Max 10 pending nonces per player at once |
| Nonce req rate | 30 requests per 5 000 ms per player |
| Strike system | Violations accumulate weighted strikes → warn (3) → kick (5) → ban (8) |

## TypeScript / NUI — `@matehun/rpc`

### Setup — `RpcProvider`

Wrap your app once. It creates the `RpcClient` backed by `FiveMTransport` automatically. Pass a `MockTransport` during local development.

```tsx
import { RpcProvider, MockTransport } from '@matehun/rpc'

const mock = new MockTransport()
mock.on('getVehicleSpeed', () => ({ kmh: 120 }))

export default function App() {
    return (
        <RpcProvider mock={import.meta.env.DEV ? mock : undefined}>
            <UI />
        </RpcProvider>
    )
}
```

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `resourceName` | `string` | `GetParentResourceName()` | FiveM resource name used in fetch URL |
| `timeoutMs` | `number` | `10000` | Global timeout for all calls |
| `mock` | `MockTransport` | — | Replaces real transport in dev |

---

### `useRpcQuery`

Calls a Lua handler **on mount** and tracks loading/error state. Use `server: true` to route through the `callServer` proxy to a `Rpc:RegisterServerEvent` handler.

```tsx
const { data, loading, error, refetch } = useRpcQuery<{ kmh: number }>(
    'getVehicleSpeed',
    {},
    { server: false }
)
```

| Option | Type | Description |
|--------|------|-------------|
| `enabled` | `boolean` | Set `false` to skip the initial call |
| `server` | `boolean` | Routes through `Rpc:CallServer` on the client |
| `timeout` | `number` | Override per-call timeout |

---

### `useRpcMutation`

**Manually triggered** call. Returns `mutate`, `loading`, `error`, and `reset`.

```tsx
const { mutate, loading, error } = useRpcMutation<{ itemName: string }, { count: number }>(
    'getItemCount',
    { server: true }
)

const handleCheck = async () => {
    const result = await mutate({ itemName: 'water' })
    if (result) console.log(result.count)
}
```

---

### `useNuiEvent`

Listens for messages pushed by `Rpc:Send` or `Rpc:SendAll` from Lua. The handler ref is kept stable — safe to use inside effects.

```tsx
useNuiEvent<{ health: number; armour: number }>('updateHud', (data) => {
    setHud(data)
})
```

---

### `useRpc`

Returns the raw `RpcClient` instance from context. Use when the higher-level hooks don't fit.

```tsx
const rpc = useRpc()

const handleClose = async () => {
    await rpc.send('closeUI', {})
}
```

---

### `RpcClient` — direct usage (no React)

When React is not involved, instantiate directly.

```ts
import { RpcClient, FiveMTransport } from '@matehun/rpc'

const transport = new FiveMTransport()
const rpc = new RpcClient(transport, { timeoutMs: 8000 })

const result = await rpc.call<{ kmh: number }>('getVehicleSpeed', {})

rpc.register('closeUI', (data) => {
    setVisible(false)
})

rpc.dispose()
```

| Method | Description |
|--------|-------------|
| `call(route, payload, options)` | Calls a Lua `Rpc:Register` client handler, awaits response |
| `callServer(route, payload, options)` | Routes through the client proxy to a `Rpc:RegisterServerEvent` handler |
| `send(route, payload)` | Fire-and-forget to Lua |
| `register(action, handler)` | Handles incoming `Rpc:Send` / `Rpc:Call` messages |
| `dispose()` | Removes the `message` listener and clears all handlers |

---

### `MockTransport`

Simulates Lua responses in-browser without a running FiveM server.

```ts
import { MockTransport } from '@matehun/rpc'

const mock = new MockTransport({ latency: 80 })

mock.on('getPlayerInfo', (payload) => ({
    name: 'TestPlayer',
    source: 1,
    ping: 12,
}))

const unregister = mock.on('getItemCount', async (payload) => {
    return { count: 5 }
})
```

Default simulated latency is `50ms`. Pass `{ latency: 0 }` to disable.

---

## Default Timeout

All calls default to **10 000 ms**. Overridable at three levels:

1. `RpcProvider` prop — `timeoutMs`
2. Per hook — `options.timeout`
3. Lua side — `timeout` parameter on `Call` / `CallServer`
